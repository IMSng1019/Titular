# Titular GUI、语言与富文本编辑器设计

## 目标

把 `/titular` 从当前的直接标签页界面改成权限感知的引导入口，并补充客户端本地中文/英文切换，以及以当前编辑玩家真实用户名为中心的前缀/后缀富文本编辑体验。

## 用户流程

打开 `/titular` 后先进入引导页，而不是直接进入某个管理标签页。

- “切换头衔”：所有玩家可见，打开当前玩家可用头衔列表，激活或清除当前头衔。
- “选择主组”：`ADMIN` 与 `SUPERADMIN` 可见，打开主组列表。主组变化后，服务端重新计算该玩家可用头衔池。
- “设置头衔”：仅 `SUPERADMIN` 可见，打开管理工作区，继续承载称号、组、玩家和服务器显示模式管理。
- 语言按钮：所有玩家可见，打开本地语言选择。切换后立即刷新当前屏幕，并写入客户端配置；不通过网络发送。

所有子页面提供返回引导页的按钮。权限只用于投影入口，真正的修改仍由服务端重新校验。

## 客户端语言

新增客户端语言管理器，维护 `ENGLISH` 与 `CHINESE` 两个 locale，默认英文。locale 保存到客户端配置目录的独立 JSON 文件，不修改服务器 `TitularSettings`，也不改变 Minecraft 全局语言。UI 文本通过统一的客户端翻译辅助方法获取，缺失中文键时回退英文；网络错误文本仍显示服务器返回内容。

资源新增 `zh_cn.json`，并把现有界面字符串迁移到相同的键集合。语言设置面板使用单选/分段按钮，选择后清理并重建屏幕控件，避免重启客户端才能看到变化。

## 富文本编辑器

超级管理员编辑称号时使用一个横向预览区域：

`[可编辑前缀]  [当前编辑玩家真实用户名]  [可编辑后缀]`

用户名部分只读，前缀和后缀各自绑定一个 `StyledTextDocument`。编辑目标为自己时使用客户端当前用户名；编辑在线玩家时使用快照中的原始名称；离线玩家优先使用客户端缓存的 `GameProfile` 名称，无法解析时回退 UUID。服务端存储格式仍是现有 `TitleDefinition(prefix, suffix)`。

工具栏提供颜色色板、粗体、斜体、下划线、删除线和重置。样式只作用于当前选区；无选区时改变后续输入样式。编辑器渲染实际样式，不显示 `§` 或 JSON。保存前生成完整前缀/后缀 `Text`，沿用现有请求编解码和服务端校验。

## 客户端结构

保留 `ClientSnapshot`、`TitularScreenState`、`ClientNetworking` 和现有请求协议。重构 `TitularScreen` 为轻量路由器，新增引导页状态和返回动作；现有管理面板改为在对应路由下安装。面板控件使用稳定的相对布局，窄屏时限制内容宽度并允许滚动，避免按钮和文本重叠。

服务器不接受客户端语言值，也不因语言变化广播快照。主组、头衔激活和超级管理员 CRUD 仍携带快照修订号，失败时保留当前页面并显示错误。

## 验证

补充纯 Java 测试覆盖：

- locale 默认值、持久化、损坏/未知值回退；
- 权限到引导按钮的投影；
- 主组改变后可用头衔池请求保持正确修订号；
- 前缀/用户名/后缀预览组合及用户名只读；
- 编辑器选区样式与现有 `StyledTextDocument` 的 run 合并。

随后运行 `gradlew test`、`gradlew build`，并至少编译客户端源码验证 Minecraft 1.20.4 GUI API 和资源键完整。
